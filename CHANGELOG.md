# Changelog

## [0.2.0] - 2026-08-19

### Added

- Professional role-aware workspace with KPI cards, operational charts, shortcuts, and complete module navigation.
- Arabic translations and a Desk-style Arabic user guide with searchable DocType navigation.
- Portable Role and Custom DocPerm fixtures for deployment to new sites.

### Changed

- Declared and documented Frappe 15.35.0 / ERPNext 15.22.2 compatibility.
- Improved publisher, package, installation, and release metadata for Ibrahim Merhi.
- Corrected Evaluation Date metadata and workspace navigation validation.

## [0.1.0] - 2026-08-18

### Added

- Employee-style public admission applications with controlled review and conversion to students.
- Quran programs, milestones, weekly individual slots, and text progression.
- Formal scientific-committee exams, error deductions, ijazah/sanad, and discipline controls.

- Institute structure, academic periods, teachers, halaqas, and students.
- Assignment, session, attendance, evaluation, Quran progress, state, and next-assignment flows.
- Teacher supervision, follow-up, and configurable operational exception detection.
- Student, teacher, halaqa, and branch analytics.
- Five operational roles with record-level permissions, workspace, fixtures, and tests.
